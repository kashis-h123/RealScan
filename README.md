**Real-Time Object and Sound Detection System**
Developed an intelligent real-time detection system capable of identifying and recognizing multiple objects and environmental sounds simultaneously through live camera and audio input. The system utilizes computer vision and audio processing techniques to provide accurate, real-time detection and classification. A user-friendly graphical interface was built to enhance accessibility and interaction.

**Key Features:**
Real-time object detection using live webcam feed
Simultaneous detection of multiple objects
Sound recognition and classification
Interactive desktop GUI for easy operation
Fast and accurate detection with visual feedback

**Technologies Used:** Python, OpenCV, Tkinter, NumPy, Machine Learning, Audio Processing Libraries
